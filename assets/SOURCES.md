# Fontes dos recursos visuais

- `badges/redis.svg`: badge local com logo Redis do Simple Icons (https://simpleicons.org/), incorporado diretamente ao SVG.

- `banner.svg`: banner aprovado de Pedro Yada (anteriormente banner-v2.svg). Gradiente preto e verde, nome e subtítulo fixos e componentes conectados com iluminação e movimento discretos. Respeita preferência por movimento reduzido; sem imagens, fontes ou serviços externos.
- `badges/*.svg`: Shields.io — https://shields.io/
- Logos dos badges: Simple Icons — https://simpleicons.org/. As marcas pertencem aos respectivos titulares e não implicam endosso.
- Logos incorporados localmente: AWS e Java do Devicon v2.17.0 (https://github.com/devicons/devicon); LangChain, LangGraph e Qdrant do Simple Icons (https://simpleicons.org/). Os SVGs incluem os ícones diretamente, sem requisições externas.

As imagens são cópias estáticas armazenadas no repositório. O README usa caminhos relativos e não depende dos serviços externos para carregá-las. Para alterar um elemento visual, substitua seu SVG. Publique o README e a pasta assets juntos.
